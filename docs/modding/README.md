# Modder documentation

This reference describes the PC-98 game's actual formats and the Redux implementation. It covers language-preserving Fixes, independent Windows Artwork, Rebalance, both editors and the analysis tools. The Japanese game and the tested English translation use the same numeric record identities. Translated strings can move records and branch destinations, so file offsets must be resolved against the selected input.

Machine-readable references are generated by `python tools/modmap.py`: [executable sites](Executable-Sites.csv), [event edits](Event-Edits.json) and [assembled Rebalance labels](Rebalance-Labels.json). They consume the patch modules' own definitions. Existing [numeric adjustments](../../Rebalance-Changes.csv) and [combat formulas](../../REBALANCE.md) remain the design reference.

Offsets below are hexadecimal unless a table says otherwise. Chunk numbers and array indices are zero-based. `ET0004#102` uses decimal 102; `MS0032 record 0x26` uses hexadecimal 26. All multibyte numeric fields are little-endian. Unknown fields and assumptions are explicitly identified; this is a map of established findings, not a claim that the entire game has been decoded.
