Giten Megami Tensei Redux

One download. Three enhancement patches and one optional Controls package.

This folder contains Fixes, Windows Artwork, Rebalance and the Controls, plus the complete English documentation. Keep the extracted files together.

Before you start

  1. Use a copy of your supported PC-98 .hdi game disk. Close the emulator and back up your game and saves.
  2. Playing in English? Apply Sneikkimies' English translation to its required Japanese image first. Then use the English result below. Redux retains your game's language; the translation is a separate download.
  3. For each patch: select the HDI, click Apply patch, then click Save. Processing is local; your disk is never uploaded.

Install all three patches

Follow these steps in order. Pass each newly saved HDI to the next step. Keep this guide open; the buttons open each patch in a new tab.

Optional Keyboard & Gamepad Controls

The battle target prompt and pause are necessary for these controls and are always installed or removed with them.

Apply Controls

Select the disk you play (for example Giten_WIN.hdi), click Install Controls and save Giten_Controls.hdi:

  • Target prompt: while you pick a target in battle, the text box asks “Use on whom?” (English) or 「誰に使いますか？」 (Japanese), and battle time stops, so no enemy acts during your pick.
  • Keyboard / gamepad controls: the stick walks; the D-pad moves the pointer between menu entries, options and targets; X goes to the command panel and back; A and B are the mouse buttons. For DOSBox-X, the included dosbox-x.conf already enables mapper-giten.map for an XInput pad.

Apply the control features after the other patches. Remove Controls on the same page removes the complete patch.

Prefer a different combination?

  • Original combat rules with repairs and new artwork: apply step 1, then step 3 using Giten_Fixed.hdi. Rebalance is optional.
  • Fixes only: apply step 1 and play Giten_Fixed.hdi.
  • Fixes + Rebalance, original artwork: apply steps 1 and 2 and play Giten_Rebalanced.hdi.
  • Artwork only: open step 3 and select your Japanese or English game HDI directly. It works independently.

Start the game

Mount your final HDI in the same PC-98 emulator setup that runs your original copy. The PepsimanGB pre-made hard disk also needs its companion boot floppy: mount both and boot from the floppy.

To use the included DOSBox-X configuration, put dosbox-x.conf and mapper-giten.map beside your dosbox-x.exe, final Giten_Controls.hdi, and your own companion floppy copied as Boot.fdi, then double-click the emulator. The configuration mounts the hard disk and boots the floppy. For a self-booting image or an existing emulator setup, see CONTROLS.md.

Restart the emulator and load an in-game save after changing patches. Emulator save states retain the previously running program.
